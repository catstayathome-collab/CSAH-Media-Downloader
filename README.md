# CSAH Media Downloader

Downloads and update feeds for CSAH Media Downloader (macOS and Windows).

- Website and download buttons: https://catstayathome.com/
- Installers are attached to the release pages of this repository.
- `updates/` holds the signed lists that the apps read through
  `https://downloads.catstayathome.com/`. They are published here as the
  public record of what was released.

This repository does not contain source code.
