# CSAH Media Downloader

Downloads and update feeds for CSAH Media Downloader (macOS, Windows and Android).

- Website and download buttons: https://catstayathome.com/
- Installers are attached to the release pages of this repository.
- `updates/` holds the lists that the apps read through
  `https://downloads.catstayathome.com/`. They are published here as the
  public record of what was released. The macOS, Windows and notice lists are
  signed; the Android list is not, because Android installs an update only
  when it is signed with the same key as the installed app.

This repository does not contain source code.

CSAH Media Downloader（macOS／Windows／Android）的下載與更新清單。

- 官網與下載按鈕：https://catstayathome.com/
- 安裝檔放在本儲存庫的發行頁。
- `updates/` 是 App 透過 `https://downloads.catstayathome.com/` 讀取的清單，在此公開留存。macOS、Windows 與公告清單有簽章；Android 清單不簽章，因為 Android 只接受與已安裝 App 同一把金鑰簽章的更新。

本儲存庫不含原始碼。
